# Lessons Learned — Gara Yaka Portfolio

## UI/UX Design Patterns
- **Manual Preference**: The user prefers explicit Tailwind classes for section headers (e.g., `font-jakarta font-extrabold text-[clamp(...)]`) over abbreviated utility classes (e.g., `.section-title`). This preserves fine-tuned visual weight.
- **Eyebrow Rigor**: Technical eyebrows should maintain their specific prefixes (`▶▶` or `///`) and manual pill layouts (`bg-muted/50 border border-border/50`) rather than being abstracted into a single class that loses detail.

## Workflow Patterns
- **Standardization**: When standardizing, focus on the *values* (colors, border-radius, shadows) rather than the *structure* if the user likes the current structure.
